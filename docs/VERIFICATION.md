## Isolated verification

The test suite exercises the reference handler over actual loopback HTTP against three simulated providers with synthetic payloads. Cloud transport is redirected to a loopback simulator; unknown destinations are rejected. The production health thread is not started by the fixture; tests explicitly control health state.

Cases include first-provider success, HTTP/connection/timeout failures, invalid JSON, incomplete/error responses, secondary success, strict provider order, cloud translation, fresh reachability gate, relaxed policy, all-provider failure, malformed cloud output, missing credential, unsupported cloud input, chat/tool/schema translation, disabled/unhealthy providers, synthetic model listing, single-chunk streaming, validation, and request size limits.

Timeout tests shorten actual loopback waits to 50 ms while asserting production timeout arguments. TLS handshakes, real 180-second waits, OpenAI credentials/billing, background health-loop timing, proxy health transitions, concurrent load, and full Paperless workflow integration are not covered.
